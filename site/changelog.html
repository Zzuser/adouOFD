更新日志

阿豆OFD 的版本变化。完整英文记录见 GitHub 仓库的 CHANGELOG。

当前版本 1.2.0 2026-11-05 Windows x64

2026-11-05

1.2.0

  • 新增深色模式：默认跟随 Windows 深浅色，也可固定浅色或深色；阅读器、文本 / Markdown 编辑器、弹窗以及转换、合并、拆分、打印界面均已适配。
  • OFD / PDF 纸张、缩略图和打印预览保持白色，深色下依然按白色纸张阅读和核对版式。
  • 文件关联按 .ofd / .pdf / .md 分别显示状态并提供“设为默认”入口；修复 Capabilities 已注册但扩展缺失时的状态误报。
  • 合并、批量转换、拆分、插入按钮在缺输出目录或源文件时保持可点，点击后明确提示缺少哪一步。
  • 深色吉祥物只补齐透明留白，保留原画，不重绘、不留接缝。

2026-11-04

1.1.4

  • 设置页重新设计：文件关联状态按 .ofd / .pdf / .md 分组展示，操作按钮区分主次，移除关联与清除最近文件改为行内确认。
  • 新增“版本与更新”卡片，可直接检查更新并查看当前版本与更新来源。
  • 新增最近文件记录清理；加载与操作过程增加骨架、进度和结果反馈。
  • 更新源切换到 CNB Release：版本清单和安装包都从 CNB 下载，不再占用 MinIO 带宽。
  • GitHub 构建产物同步发布到 GitHub Release 与 CNB Release。

2026-11-04

1.1.3

  • 更新下载链路兼容 CNB Release 镜像，为后续切换国内下载源做准备；本版本仍从 MinIO 主源检查和下载更新。
  • GitHub 构建的安装包同步发布到 CNB Release，提供 GitHub 之外的下载镜像。
  • 维护版本，界面与功能无变化。

2026-11-04

1.1.2

  • 安装器的“文件关联”和“创建桌面快捷方式”默认勾选，新安装和覆盖升级都生效。
  • 更新包通过 SHA256 校验后，关于页可直接点击“运行安装包”启动覆盖升级。

2026-11-04

1.1.1

  • 修复只读 OFD 合并、拆分与插入失败；修复组合对象签章偏移；非 ISO 附件日期不再中止转换。
  • 合并 PDF 新增 Auto / Vector / Image 三档；普通发票可用 Image 大幅减小体积。
  • 关于页新增手动检查更新，支持应用内下载与 SHA256 校验。

2026-11-03

1.1.0

  • 用 Javalin 6 替换 Spring Boot，移除 Spring / Tomcat / Logback 等依赖，引擎启动约 0.4–0.8 秒。
  • 后端 jar 从 48.8 MB 缩减到 36.2 MB，服务层与框架解耦。

2026-11-03

1.0.0

  • 首个稳定版：页面旋转、最近文件、文档属性、加密 PDF、Markdown / 文本编辑与 PDF 导出。
