## Issues

Use GitHub Issues for reproducible bugs and feature requests:

https://github.com/Zzuser/adouOFD/issues

Include the application version, Windows version, file type and page count, and the exact steps to reproduce. Do not upload real invoices, contracts, or other sensitive documents; generate a synthetic sample instead.

For security vulnerabilities, follow `SECURITY.md` and do not open a public issue with exploit details.

## Not supported

- Recovering corrupted or password-protected documents
- Bypassing document permissions or signature controls
- Installing or debugging third-party software on the user's machine
