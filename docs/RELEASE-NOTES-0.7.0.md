## 主要更新

- **全文搜索**：`Ctrl+F` 或阅读器“查找”，跨页扫描 OFD / PDF 文字层，增量结果、扫描进度、当前命中高亮与精确定位，支持区分大小写。
- **Windows 文件关联**：独立 `AdouOFD.OFD` / `AdouOFD.PDF` ProgID 与两套文件图标；双击文件并入当前窗口；不覆盖已有默认应用。安装向导提供“关联 .ofd / .pdf 文件类型”任务。
- **Inno Setup 安装包**：固定 AppId 与版本号，支持覆盖升级；保留安装目录与上次任务选择；静默升级未显式指定任务时保留现有文件关联。
- **设置页**：Windows 文件关联从“关于”拆到独立“设置”页，可注册/修复、设为默认、打开系统设置、移除。
- **开源许可**：关于页增加组件摘要与“第三方声明 / MIT 许可 / 打开许可目录”；完整许可文本随安装包分发到 `resources/notices/`。
- 保留：OFD/PDF 阅读、逐字选择、转换、批量转换、合并、多标签、品牌 UI。

## 升级说明

- 可直接覆盖安装同为 Inno AppId 的 0.6.0 版本；安装目录、文件关联任务与版本信息会保留。
- 如果之前安装的是 NSIS 构建或临时构建，建议先卸载旧版本，避免出现两个卸载项。
- Windows 10/11 不允许程序静默修改默认应用；如 `.ofd` 仍由其他程序打开，请在“设置 → 设为默认…”或系统默认应用中选择阿豆OFD。
