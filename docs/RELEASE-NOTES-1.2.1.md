# 阿豆OFD 1.2.1

## 重点变化

- 本地引擎跟随主进程退出：Electron 崩溃或被强制结束时不再遗留常驻的 java.exe；启动时自动清理超过 24 小时的引擎与打印临时目录。
- 新增页面渲染缓存上限（每个文档 384MB），长文档反复缩放不会无限占用磁盘；引擎意外重启后会按路径恢复文档标签，无法恢复的加密 PDF 会明确提示。
- 阅读性能优化：不同文档可并行解析与渲染，图片优先出图、文字层随后加载，页面图片只保留当前页附近的 4 页，长文档浏览不再持续累积内存。
- 编辑器改为按需加载，首屏脚本从 3.37MB 降到约 0.88MB；KaTeX 字体只保留 Chromium 实际使用的 woff2，字体体积从 1.17MB 降到 0.29MB。
- 修复导出 PDF 后深色窗口底色变浅、公式字体未就绪时导出缺字两类问题；打开大文档的超时从 20 秒放宽到 120 秒。

## 升级说明

- 1.2.0 用户：设置 → 版本与更新（或关于）→ 检查更新 → 下载并校验 SHA256 → 运行安装包。
- 覆盖安装会保留设置、最近文件、外观偏好与既有文件关联。
- 安装包未签名，Windows SmartScreen 可能提示“未知发布者”；请以发布页或应用内显示的 SHA256 为准。

## 验证

- 后端 71/71 测试通过；桌面端 typecheck 与生产构建通过。
- 主 UI 冒烟、文本 / Markdown 冒烟通过，覆盖页面渲染、旋转、全文搜索、打印、批量转换、合并、加密 PDF 与标签切换。
- 父进程退出看门狗在独立进程环境中实测：父进程结束后引擎在数秒内退出。
