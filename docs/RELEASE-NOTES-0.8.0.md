## 主要更新

### 应用内打印

- 阅读器“打印”或 `Ctrl+P` 打开打印面板：左侧设置、右侧实时预览与分张导航。
- 打印机：系统默认打印机或指定打印机；打印任务直接发送到所选打印机。
- 常用选项：份数 1–99、灰度、全部/当前页/自定义页码范围、奇偶页、逆序。
- 纸张：A3 / A4 / A5 / A6 / B5 / Letter / Legal / Tabloid，纵向/横向，默认 10mm / 无边距 / 自定义四边页距。
- 一张多页：每张 2 / 4 / 6 / 8 / 9 页；8 页为 2 列 × 4 行；支持按行 Z / 按列 N 排列与打印边框。
- 双面：单面、长边翻页、短边翻页（取决于打印机驱动支持）。
- 页面按所选页数自适应 300 / 200 / 150 DPI 渲染；预览与打印使用同一套排版计算。

### 结果快捷打印

- 单文件转换结果、批量转换结果行与合并结果都新增“打印”按钮，不需要先把结果打开到阅读器。
- 结果已在标签中打开时复用现有会话；否则临时打开并在关闭打印面板后释放，不新增标签。
- 打印面板支持在转换结果弹层、批量页与合并页上直接覆盖显示。

### 其他

- 打印失败在面板内提示；打开大结果时显示“正在准备打印…”。
- README、PRD、CHANGELOG 与界面截图同步更新。
- 后端测试与 UI 冒烟覆盖打印面板、N-up、纸张、灰度与结果入口。

## 升级说明

- 可直接覆盖安装 0.7.1（同一 Inno AppId），安装目录、文件关联任务与设置保留。
- Windows 10/11 不允许程序静默修改默认应用；如 `.ofd` 仍由其他程序打开，请在“设置 → 设为默认…”或系统默认应用中选择阿豆OFD。

## 已知限制

- 当前打印是页面图像（300/200/150 DPI），超大文档的准备时间与内存随页数增长。
- 纸张、双面、颜色能力取决于打印机驱动；暂不提供驱动属性（纸盒、打印质量）面板。
- 小册子、拆分/裁切、仅打印文档不含标注、水印/页码/页眉页脚属于后续版本。
- 当前 代码签名申请未获批准，构建未签名。
- PDF → OFD 的文字能否选中取决于源 PDF 字体；扫描件没有文字层，无法全文搜索。
- OFD → PDF 矢量导出可能嵌入完整中文字体，文件体积较大。
- 合并结果不保证保留各文件的目录/书签。
- Windows 默认应用切换需要用户在系统界面确认。
