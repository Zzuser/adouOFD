# 阿豆OFD 1.1.0

## 重点变化

- 本地引擎由 Spring Boot 迁移到 Javalin 6.7.0（内嵌 Jetty 11），运行时不再包含 Spring。
- 打包版引擎热启动约 0.42 秒（1.0.0 约 1.25 秒），首次启动约 0.97 秒；后端 jar 从 48.8 MB 降到 36.2 MB。
- HTTP API、文档处理与界面功能保持不变；关于页显示“运行时 Javalin 6.7.0”。
- 后端 54 个测试、完整 UI 冒烟与打包版打开 PDF/OFD 验证通过。

## 升级说明

- 直接覆盖安装 1.1.0；文件关联与最近文件保留。
- 首次启动会在用户数据目录生成引擎缓存（约 22 MB），之后的启动更快；删除该缓存不影响文档。
- 安装包仍未签名（SignPath 审核中）。
