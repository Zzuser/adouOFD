## 主要更新

### 拆分与插页

- 新增独立“拆分与插页”标签页。
- 拆分支持每页一份、每 N 页一份、按自定义页码区间拆分；可设置文件名前缀和输出目录，同名结果自动加序号，不覆盖已有文件。
- 插页支持把另一个 OFD / PDF 的指定页插入主文档开头、指定页前或末尾。
- 插入文档与主文档格式不同时，先转换插入页，再按主文档格式输出。
- 拆分与插页共用转换/合并的重任务队列，支持进度、停止、页数校验和原子落盘。

### 页面预览

- 拆分预览显示全部页面缩略图；每 N 页和按区间模式用颜色序号标出输出分组。
- 按区间拆分时，未选中的页面自动淡化。
- 插页同时显示主文档和插入文档预览；主文档用虚线标出插入位置，插入文档高亮将插入的页面。
- 预览使用独立文档会话，不占用阅读器标签的会话，不会把已打开的文档挤掉。

### 交互

- 拆分/插页结果可直接查看、打印或在文件夹中定位。
- 拆分结果按文件列出页数，并可逐个操作。
- 预览区固定放在操作区下方，文件选择、参数设置和结果操作集中在页面上方。

## 升级说明

- 可直接覆盖安装 0.8.0（同一 Inno AppId），安装目录、文件关联任务与设置保留。

## 已知限制

- 拆分/插页结果不保证保留原文档的目录/书签。
- “每页一份”会生成多个文件；单次最多生成 300 个拆分文件，超出时请改用每 N 页或按区间拆分。
- OFD 拆分/插页会先复制并修复样式/资源再处理；大文档的耗时随页数增长。
- 混合格式插页的文字可选中性取决于源文件的转换能力边界。
- 当前 SignPath Foundation 开源签名申请审核中，构建未签名。
- PDF → OFD 的文字能否选中取决于源 PDF 字体；扫描件没有文字层，无法全文搜索。
- OFD → PDF 矢量导出可能嵌入完整中文字体，文件体积较大。
- 合并结果不保证保留各文件的目录/书签。
- Windows 默认应用切换需要用户在系统界面确认。
