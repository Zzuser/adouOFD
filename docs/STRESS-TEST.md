## 2. 引擎级结果

启动真实 jar，逐文件打开，渲染首/中/末页（96 DPI 与 24 DPI 缩略图），并提取文字层（逐字片段）。

| 文件 | 打开 | 目录 | 96 DPI 首/中/末页 | 24 DPI 首/中/末页 | 文字层首/中/末页 | 引擎 RSS |
| --- | ---: | ---: | --- | --- | --- | ---: |
| 100 页图片 PDF | 147ms | 0 项 | 775 / 365 / 565ms | 53 / 292 / 299ms | 15ms/35 / 22ms/36 / 17ms/37 片段 | 295MB |
| 91 页 OFD | 2619ms | 0 项 | 4058 / 433 / 230ms | 1074 / 115 / 87ms | 76ms/1971 / 39ms/2110 / 32ms/1700 片段 | 456MB |
| 800 页矢量 PDF | 411ms | 96 项 / 45ms | 327 / 321 / 203ms | 128 / 64 / 54ms | 199ms/3966 / 95ms/3968 / 79ms/3968 片段 | 476MB |

说明：

- 冷启动、系统杀软/磁盘负载会造成明显波动；800 页 PDF 另一次运行打开 70ms、末页 42ms，91 页 OFD 另一次打开 462ms、首/末页 634/51ms。表格保留较慢的一次运行作为上限参考。
- 首屏包含字体/图片首次解码，明显慢于后续页；后续页稳定在约 40–600ms（PDF）与 50–433ms（OFD）。
- 逐字文字层按字形输出（800 页 PDF 每页约 3968 个片段），单页提取约 9–199ms；OFD 每页约 1700–2110 个片段，约 32–76ms。扫描件图片 PDF 仅能提取叠加文字，不能识别图中文字。
- RSS 在逐个打开大文件后累积到约 476MB（JVM 堆未立即归还操作系统），仍低于 `-Xmx768m`。

## 3. UI 结果

真实 Electron 打开文件，滚动到中页/末页、切到末张缩略图、加载目录，统计耗时、DOM 与 JS 堆。

| 文件 | 页数 | 页面节点 | 缩略图节点 | 首屏 | 中页 | 末页 | 末张缩略图 | 目录 | JS 堆 | 运行时错误 |

| 100 页图片 PDF | 100 | 100 | 100 | 1548ms | 924ms | 617ms | 217ms | - | 10MB | 无 |
| 91 页 OFD | 91 | 91 | 91 | 1862ms | 405ms | 390ms | 224ms | - | 38MB | 无 |

截图（800 页）：[docs/screenshots/stress-800p.png](screenshots/stress-800p.png)

说明：

- 逐字文字层会增加 DOM 节点：800 页 PDF 在访问 3 页后 JS 堆约 73MB（仅在已渲染页面挂载文字层），仍未出现卡死或错误。
- 800 页文档一次性创建 800 个页面占位与 800 个缩略图按钮，滚动、跳页、目录、末张缩略图均正常。
- 跳转到中页/末页约 0.3–1.6s，包含后端渲染、图片传输与文字层生成；图片 PDF 因单页图片较大，耗时高于矢量 PDF。
- 所有 UI 压测均无渲染进程异常或控制台错误。

## 4. 结论与后续

**通过项**

- 800 页文档可打开、跳页、缩略图导航、目录导航，无崩溃。
- 20MB 图片 PDF 与 91 页 OFD 正常打开与渲染。
- 平滑滚动、缩略图懒加载、第 1 页优先渲染策略在压力下工作正常。

**已知边界**

- 未测试 1000 页以上或 100MB 以上文件；页面/缩略图 DOM 数量线性增长，后续可考虑虚拟列表。
- 引擎会同时保留最多 8 个会话；同时打开多个超大文件时 RSS 可能接近堆上限，M1.2 可加入“大文档会话优先淘汰/内存预算”。
- 压力测试生成的 91 页 OFD 没有书签，因此目录显示“该文档没有目录”；PDF 96 项目录已验证。OFD Outlines/Bookmarks 解析已实现，待拿真实带书签公文回归。
- 本报告为当前机器实测，不同磁盘/杀软/内存环境下数值会波动。
