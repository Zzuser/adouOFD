# 阿豆OFD 1.2.2

## 重点变化

- 修复 PDF 转 OFD 后发票预览、打印和导出缺字：转换生成的裁剪区按自身 Boundary 定位，旧版预览渲染把它画到了页面左上角，导致被裁剪的文字整块消失；现在渲染前在内存中补上平移，源文件不做修改，WPS 等阅读器本来就能正常显示。
- 渲染补偿按后端区分：组合对象在两个后端都补 Boundary 平移；裁剪区只给图片渲染补，矢量 PDF 导出本身已正确处理，补了会二次偏移。
- 预览开启抗锯齿：小字号宋体的 0.05mm 横画以前在 144 DPI 下不足 1 像素会被整条丢弃，表现为笔画断裂、文字发虚；现在以灰度覆盖呈现，效果与 PDF 阅读器一致。
- 抗锯齿只用于预览与保真兜底导出，合并时的“小体积”图像导出保持原样，避免安装包之外的输出体积膨胀。

## 升级说明

- 1.2.1 用户：设置 → 版本与更新（或关于）→ 检查更新 → 下载并校验 SHA256 → 运行安装包。
- 覆盖安装会保留设置、最近文件、外观偏好与既有文件关联。
- 安装包未签名，Windows SmartScreen 可能提示“未知发布者”；请以发布页或应用内显示的 SHA256 为准。

## 验证

- 后端 81/81 测试通过，其中新增裁剪区与抗锯齿回归测试用合成 OFD 锁定两个渲染后端的行为差异。
- 主 UI 冒烟、文本 / Markdown 冒烟通过，无渲染进程运行时错误。
- 真实电子发票实测：预览 144/300 DPI 文字完整且细笔画连续，矢量 PDF 导出与源 PDF 版面一致。
