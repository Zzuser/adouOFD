# 阿豆OFD 1.1.4

## 重点变化

- 设置页重新设计：文件关联状态按 .ofd / .pdf / .md 分组展示，操作按钮区分主次，移除关联与清除最近文件改为行内确认。
- 新增“版本与更新”卡片，可直接检查更新，并查看当前版本与更新来源。
- 新增最近文件记录清理；加载与操作过程增加骨架、进度和结果反馈。
- 更新源切换到 CNB Release：版本清单和安装包都从 CNB 下载，不再占用 MinIO 带宽。

## 升级说明

- 1.1.3 用户：设置 → 版本与更新（或关于）→ 检查更新 → 下载并校验 → 运行安装包。
- 若当前版本仍读取旧 MinIO 清单，请手动安装一次 1.1.4；之后会自动使用 CNB 更新源。
- 覆盖安装保留设置、最近文件与既有文件关联。
- 安装包未签名，Windows SmartScreen 可能提示“未知发布者”；请以发布页/应用内显示的 SHA256 为准。

## 验证

- 后端测试通过；前端 typecheck/build 通过。
- 设置页在真实 UI 中验证：检查更新、清除最近文件确认、移除文件关联确认。
- CNB Release 上传、匿名下载与 SHA256 校验通过。
