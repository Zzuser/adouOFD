# 阿豆OFD 1.1.2

## 重点变化

- 安装器的“文件关联”和“创建桌面快捷方式”默认勾选，新安装和覆盖升级都生效；不再沿用上次安装时的任务选择。
- 更新包下载并通过 SHA256 校验后，关于页新增“运行安装包”按钮，可直接启动安装程序完成应用内升级；安装程序会关闭正在运行的应用并覆盖安装。
- 升级时文件关联与快捷方式默认勾选，仍可在安装向导中手动取消。

## 升级说明

- 1.1.1 用户：关于 → 检查更新 → 下载并校验 → 运行安装包，按向导完成升级。
- 覆盖安装保留设置、最近文件与既有文件关联；安装任务默认勾选，可手动取消。
- 安装包未签名，Windows SmartScreen 可能提示“未知发布者”；请以发布页/应用内显示的 SHA256 为准。

## 验证

- 后端 68 项测试通过；前端 typecheck/build 通过。
- 安装器脚本任务默认值为勾选，且 `UsePreviousTasks=no`，升级不会复用上次的取消状态。
- 应用内检查更新、下载、SHA256 校验和“运行安装包”入口通过真实 UI 验证。
