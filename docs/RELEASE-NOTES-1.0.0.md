## 1.0 主要更新

### Markdown 与文本编辑

- 支持 `.md` / `.markdown` / `.txt`：打开、拖放、启动参数、第二实例与最近文件均接入；文本标签不依赖 Java 引擎。
- CodeMirror 6 编辑器 + GFM 实时预览：表格、任务列表、代码高亮、本地图片、相对链接、页内锚点。
- 分栏 / 编辑 / 预览三种模式；分栏分隔线可拖动（20%–80%，记忆比例，双击恢复 1:1）。
- 标题目录跳转；编辑区与预览区同步滚动（可关闭）。
- `Ctrl+S` 保存；编码 / 换行 / 行数 / 字数状态栏；标签页未保存黄点。
- UTF-8/BOM、UTF-16 LE/BE、GB18030 自动识别并保持编码、BOM 与 CRLF/LF；16 MB 上限；原子写入。
- 文件被其他程序修改时提示覆盖保存或重新加载；关闭标签支持“保存并关闭 / 不保存关闭 / 取消”；退出应用前确认未保存内容。
- Markdown 预览可导出为 A4 PDF（只输出正文，包含本地图片、表格、代码高亮与分页控制）。

### 首页与入口

- 空状态改为“打开或新建文档”，提供“打开文档 / 新建 Markdown / 新建文本”。
- 移除 OFD/PDF 示例按钮；示例仍由后端接口供自动化测试使用。
- 顶部说明更新为阅读与编辑 OFD / PDF / Markdown / 文本文档。

### 阅读器与文档能力

- 页面旋转：当前页或全部页左右旋转、按页重置；视图级，不修改源文件；缩略图、文字层、搜索定位、打印预览同步。
- 最近文件：最多 20 条，去重、缺失清理，支持重新打开、定位、移除与清空。
- 文档属性：格式、页数、体积、页面尺寸、元数据与签名条目只读展示（明确不验签）。
- 加密 PDF 密码打开：密码仅用于本次打开，不保存、不写入日志。

### Windows 集成

- `.md` 注册独立 ProgID `AdouOFD.MD` 与 `md-file.ico`，加入“打开方式”和默认应用列表。
- 安装向导关联任务扩展为 `.ofd` / `.pdf` / `.md`；卸载时同步清理，不覆盖已有默认应用。
- OFD / PDF / Markdown 文件图标统一为猫脸 + 折角 + 标签版式。

## 升级说明

- 可直接覆盖安装 0.9.0（同一 Inno AppId），安装目录、文件关联任务与设置保留。
- Windows 10/11 不允许程序静默修改默认应用；如 `.ofd` 仍由其他程序打开，请在“设置 → 设为默认…”或系统默认应用中选择阿豆OFD。
- `.markdown` 仅在应用内支持，不注册系统关联；`.md` 与 OFD/PDF 一样提供“打开方式”注册。

## 已知限制

- Markdown / 文本编辑上限 16 MB；本地图片只展示已打开文档所在目录内的图片，网络图片不加载。
- Markdown 导出 PDF 固定 A4 与当前预览内容，不包含编辑器工具栏；超宽表格可能被裁切。
- 当前 代码签名申请未获批准，构建未签名，SmartScreen 可能提示“未知发布者”。
- PDF → OFD 的文字能否选中取决于源 PDF 字体；扫描件没有文字层，无法全文搜索。
- OFD → PDF 矢量导出可能嵌入完整中文字体，文件体积较大。
- 合并/拆分结果不保证保留各文件的目录/书签。
- Windows 默认应用切换需要用户在系统界面确认。
