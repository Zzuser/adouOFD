# 阿豆OFD 1.2.0

## 重点变化

- 新增深色模式：默认跟随 Windows 深浅色，也可在“设置 → 外观”固定浅色或深色。侧栏、页头、卡片、阅读器、文本 / Markdown 编辑器、弹窗以及转换、合并、拆分、打印界面都已适配；OFD / PDF 纸张、缩略图和打印预览保持白色。
- 文件关联改为按 `.ofd` / `.pdf` / `.md` 分别显示状态，并提供各自的“设为默认”入口；点击会打开本应用的 Windows 默认应用页，按扩展逐项确认。
- 修复文件关联误报：Capabilities 已注册、但某个扩展的 OpenWithProgids 缺失时，不再显示“未注册”，而是标出“需修复”；进入设置页或窗口重新聚焦时自动刷新，安装版启动时也会自动补齐缺失扩展。
- 合并、批量转换、拆分、插入的主按钮不再因为未选输出目录或源文件而禁用；点击后会明确提示还缺哪一步，只有任务运行中才禁用。
- 深色模式下空状态与“关于”页的吉祥物保留原画，只补齐透明留白，不重绘、不留接缝。

## 升级说明

- 1.1.x 用户：设置 → 版本与更新（或关于）→ 检查更新 → 下载并校验 SHA256 → 运行安装包。
- 文件关联：如果 `.pdf` 显示“需修复”，点“注册 / 修复”即可；安装版启动时也会自动补回缺失扩展。
- 深色模式默认跟随系统；可在“设置 → 外观”固定为浅色或深色。
- 覆盖安装会保留设置、最近文件与既有文件关联。
- 安装包未签名，Windows SmartScreen 可能提示“未知发布者”；请以发布页或应用内显示的 SHA256 为准。

## 验证

- 前端 typecheck / build 通过，后端无改动。
- 主 UI 冒烟与文本 / Markdown 冒烟通过。
- 深色 / 浅色、系统跟随、设置页注册状态与默认应用入口均做真实界面验证。
- 文件关联状态在实际注册表（Capabilities 已注册、`.pdf` 的 OpenWithProgids 缺失）下验证。
