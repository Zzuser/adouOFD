# 阿豆OFD 1.1.1

## 重点变化

- 修复 12306 铁路电子客票签章偏移：组合对象未声明 CTM 时按 Boundary 定位，查看、打印和导出 PDF 时签章恢复水平居中。
- 修复只读 OFD 合并失败：微信/WPS 缓存中的只读票据在合并、拆分/插页时不再因临时副本只读而中止；写入失败会提示“只读或被占用”。
- 修复非 ISO 附件日期导致 OFD→PDF 转换中止：例如 `2026-5-11 11:50:30` 的附件会被跳过并告警，正文继续导出。
- 合并 PDF 新增三档：自动（默认，超大时转图像）、矢量（文字可选中）、图像（体积小、不可选中）。普通发票可选图像把约 92 MB 压到约 1 MB；27 张火车票约 1.18 MB。
- “关于”新增检查更新：手动读取 HTTPS 版本清单，应用内下载安装包、显示进度、校验 SHA256，并打开所在文件夹；不自动运行安装包。

## 验证

- 后端 68 项测试全部通过，覆盖只读合并、非 ISO 附件日期、签章定位、PDF 体积回退和三档 PDF 模式。
- 桌面 typecheck/build 通过；真实 UI 验证检查更新、下载与 SHA256 校验。
- 普通电子发票的探测、渲染、OFD/PDF 合并通过；WPS 打开源文件不阻塞处理，打开输出文件时覆盖会得到明确提示。

## 升级说明

- 直接覆盖安装 1.1.1；文件关联、设置与最近文件保留。
- 安装包未签名；下载后请以发布页的 SHA256 为准。
- 更新检查只在用户点击“关于 → 检查更新”时联网，不上传文档或个人信息。
- 安装包下载完成后由用户手动运行，当前不做自动安装。
